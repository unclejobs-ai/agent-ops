# Part 0. 시작하며

## 0-1. 표지

- Claude Code · Cowork · Projects · Chat 퍼펙트 가이드

## 0-2. 이 가이드가 다루는 것
- 무엇을 어디에 맡길지
- 어떻게 덜 흔들리게 쓸지
- 언제 자동화하고 언제 멈출지
- 어떻게 검수하고 이어받을지

## 0-3. 이 가이드가 안 하는 것
- 기능 백과사전처럼 모든 메뉴 다 설명하기

- 영어 문서 번역본처럼 쓰기
