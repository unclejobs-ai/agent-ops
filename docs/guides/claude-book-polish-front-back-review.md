# Review Note

원고의 핵심 논지는 이미 선명했습니다. 그래서 전체를 뒤집기보다, **표지-서문-엔딩**에만 집중해 책의 착지감을 강화했습니다.

핵심 제안은 세 가지입니다.

1. 제목을 질문형에서 **책형 타이틀**로 정리하기
   - 추천: `Claude와 일하는 법`
   - 부제: `답을 받는 사람과 결과를 만드는 사람의 차이`

2. 서문 첫머리를 더 짧고 강하게 열기
   - “같은 Claude를 써도…”로 시작해 채팅창 vs 작업 시스템 대비를 초반에 고정

3. 엔딩을 “창의성”보다 **판단·책임·작업 구조**로 닫기
   - 마지막 문장이 책의 메시지를 더 오래 남기게 함

전체적으로 원고의 장점인 실무 감각과 구조 중심 메시지는 유지했고, 책으로서의 첫인상과 마지막 인상만 더 또렷하게 sharpen했습니다.
