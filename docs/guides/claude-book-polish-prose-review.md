# Claude Book Prose Polish Review

- 원본 구조(서문/7개 장/소제목 순서)는 유지했습니다.
- 문장 단위에서 번역투로 느껴지는 표현과 반복 어조를 줄이고, 더 자연스러운 한국어 리듬으로 다듬었습니다.
- 설명이 매뉴얼처럼 딱딱해지는 구간은 practical nonfiction 톤으로 정리해, 주장-예시-정리의 흐름이 더 또렷하게 읽히도록 맞췄습니다.
- 특히 ‘그럴듯한 답변’과 ‘실제 작업 구조’의 대비가 각 장에서 더 선명하게 드러나도록 표현을 정돈했습니다.
- 내용 추가나 구조 개편보다는 line edit 중심으로 손봤기 때문에, 다음 단계에서는 저자 고유 어휘와 반복 키워드(예: 작업 구조, 검증, 맥락)의 밀도를 한 번 더 점검하면 완성도가 더 올라갈 수 있습니다.
