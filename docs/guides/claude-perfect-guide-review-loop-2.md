# Claude Perfect Guide — Review Loop 2

## 이번 루프의 목적

v2가 단순 초안 수준을 넘어서, 실제로 배포 가능한 프리미엄 가이드 원고에 가까워졌는지 점검한다.

검수 기준은 네 가지다.

1. 초보자가 빨리 이해되는가
2. 비교 예시가 충분히 강한가
3. 실무자 기준으로 신뢰할 만한가
4. 디자인 문서로 옮기기 쉬운가

---

## 총평

v1이 구조 골격이었다면, v2는 확실히 **읽히는 문서** 쪽으로 올라왔다.
특히 아래 세 가지가 좋아졌다.

- 영어 개요에서 한국어 실원고로 전환됨
- 기능 설명보다 운영 기준이 앞에 나옴
- 컨텍스트 / 비용 / 보안 / 검증 루프가 핵심 축으로 올라옴

즉 방향은 맞다.
이제부터는 “더 설명할까?”보다 **“더 날카롭게 덜어낼까?”**가 중요하다.

---

## 이번 버전의 강점

### 1. 포지셔닝이 살아났다
표지 카피와 1장 메시지가 좋아졌다.
특히 아래 축이 분명하다.

- 챗봇이 아니라 작업 시스템
- 기능보다 운영 구조
- 잘 쓰면 에이전트, 못 쓰면 비싼 챗봇

이건 충분히 메인 카피 자산이 될 수 있다.

### 2. 비교축이 훨씬 강해졌다
좋은 가이드는 설명보다 비교가 빨라야 한다.
v2는 아래 비교축이 살아 있다.

- Chat / Projects / Cowork / Claude Code
- 좋은 요청 / 나쁜 요청
- 자동화 가능 / 사람 검수 필요
- CLAUDE.md / Skill / Subagent / Hook / MCP
- Chat형 AI / IDE 도구 / Claude Code
- Claude Code / Cowork

이 정도면 초보자 이해 속도가 확 올라간다.

### 3. 실무자 신뢰 포인트가 들어왔다
컨텍스트, 비용, 보안, 검증을 숨기지 않고 전면으로 끌어올린 건 좋다.
이게 있어야 문서가 광고가 아니라 기준서가 된다.

### 4. 디자인 전환성이 좋다
지금 원고는 디자이너가 잡기 좋은 구조다.
특히 아래는 카드/표/콜아웃으로 바로 바꾸기 좋다.

- 한 줄 요약
- 비교표
- 나쁜 예시 / 좋은 예시
- 실패 패턴
- 페이지 타입 가이드

---

## 아직 부족한 점

### 1. 대표 페이지 몇 장은 더 ‘강한 문장’이 필요하다
현재도 충분히 좋지만, 몇몇 장은 아직 설명형이다.
대표 페이지는 더 quotable해야 한다.

보강 예시:
- “좋은 프롬프트보다 좋은 작업장이 먼저다.”
- “긴 프롬프트보다 짧은 규칙 파일이 더 오래 간다.”
- “AI의 품질은 모델보다 검증 습관에서 무너진다.”
- “권한이 넓어질수록, 신뢰는 자동으로 생기지 않는다.”

### 2. 직무별 플레이북이 아직 얇다
지금 버전은 역할별 예시가 아주 깊지는 않다.
다음 버전에서는 최소 아래 역할별로 1페이지씩 있어야 한다.

- 개발자
- PM/기획자
- 마케터
- 1인 창업가
- 운영/리서치 담당자

### 3. ‘바로 복붙 가능한 실전 문장’이 더 많아야 한다
독자는 설명도 원하지만, 실제론 바로 써먹을 문장을 더 좋아한다.
다음 버전에는:

- 요청 템플릿
- 작업 시작 문장
- 검증 지시 문장
- 금지선 지정 문장
- handoff 문장

이 더 많이 들어가야 한다.

### 4. 브랜드 네이밍/시리즈 구조를 더 다듬을 여지가 있다
현재는 Claude Perfect Guide / Claude Code Academy / 운영 가이드가 함께 보인다.
다음 버전에선 아래처럼 정리할 필요가 있다.

예시:
- 메인 타이틀: Claude Perfect Guide
- 서브 라인: Claude Code Academy Edition
- 시리즈: Beginner / Operator / Power User

## Loop 3 우선순위

### 우선순위 1. 대표 10페이지 완성형 카피 만들기
진짜 승부는 목차보다 첫 10페이지다.
첫인상에서 “이건 다르다”가 나와야 한다.

### 우선순위 2. 직무별 플레이북 확장
역할별 예시가 늘어야 재방문 가치가 생긴다.

### 우선순위 3. 복붙 가능한 요청 템플릿 섹션 추가
독자는 결국 바로 쓰고 싶어 한다.

### 우선순위 4. 디자인 시스템 문서 분리
원고와 별도로 PDF/웹 전개용 디자인 규칙 문서를 두는 게 좋다.

## 결론

v2는 이미 충분히 방향이 좋다.
이제 해야 할 일은 더 많이 추가하는 것이 아니라,

- 더 강한 문장으로 압축하고
- 더 복붙 가능하게 만들고
- 더 직무별로 현실화하고
- 더 시각적으로 펼치기 쉽게 다듬는 것

이다.

한 줄로 요약하면:

**v2는 이제 전략 초안이 아니라, 제대로 다듬으면 바로 ‘팔리는 가이드’가 될 수 있는 수준이다.**
