# Claude Book Final Review

- 최종본은 `claude-book-polish-structure.md`를 기반으로 삼고, `claude-book-polish-prose.md`의 자연스러운 한국어 톤, `claude-book-polish-front-back.md`의 제목/서문/엔딩 개선 방향을 반영해 하나의 책 원고로 통합했습니다.
- 제목은 책형 톤이 더 강한 **`Claude와 일하는 법` / `답을 받는 사람과 결과를 만드는 사람의 차이`**로 정리했습니다.
- 서문 첫머리는 “같은 Claude, 다른 체감” 대비를 더 짧고 강하게 열어 책의 문제의식을 초반에 고정했습니다.
- 본문 구조는 7장 체제를 유지하되, 구조본의 장별 도입과 브리지 문장을 살려 책처럼 누적되는 흐름을 유지했습니다.
- 마지막 장은 ‘질문’보다 **작업 구조·판단·책임**이 남도록 엔딩을 더 단단하게 닫아, 독자가 책을 덮고 바로 적용할 행동까지 이어지게 했습니다.
